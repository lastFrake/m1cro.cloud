# m1cro.cloud

A self-hosted cloud on your own machines over Tailscale or Headscale.

- Install, artifacts and license: https://m1cro.cloud
- Questions and feedback: open an issue here.
- Vulnerabilities: report them privately under Security → Report a vulnerability.

This repository holds no code: m1cro.cloud is published as signed images and the `m1` CLI, and this repository serves its
site. It is free for noncommercial use under the [PolyForm Noncommercial License 1.0.0](LICENSE.md).
