m1cro.cloud

A self-hosted cloud on your own machines over Tailscale or Headscale.

Install

m1 is the CLI that creates, configures and runs a cloud in Docker.

curl -fsSL https://m1cro.cloud/install.sh | sh
irm https://m1cro.cloud/install.ps1 | iex
m1 create     # a new cloud
m1 reconfig   # change its network, bucket or providers
m1 restore    # a cloud from its snapshot
m1 --help
